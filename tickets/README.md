## Workflow for each ticket
1. Move status to **In Progress** (edit the table above and the ticket file).
2. **Reproduce** using the steps in the ticket.
3. **Debug** in IntelliJ (Debug mode, breakpoints) and write the root cause in the ticket.
4. **Fix** the code.
5. **Verify** with the acceptance criteria, then set status to **Done**.

Suggested order: JET-101 -> JET-102 -> JET-103 (easiest to hardest).
